What we provide?

  
Chronark brings together isolated execution, voucher payments and signed receipts for every session through one engine.

One-File SDK
CLI, MCP server and signer in one file, for Claude, Cursor and any agent.

  

  

    

      
Signed Receipts
Every session ends in a receipt: seconds, cost and a hash of the output, signed by the node that ran it.

    

      
import chronark from "chronark";
const session = await chronark.open({
  worker: "python",
  seconds: 600,
});
const out = await session.exec("python main.py");
const receipt = await session.stop();

      
Built for Agents
No API key, no account. The wallet that signs the voucher is the credential, over HTTP or MCP.
